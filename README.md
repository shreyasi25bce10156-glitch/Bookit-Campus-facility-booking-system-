# Bookit-Campus-facility-booking-system-
 BookIt is a simple desktop application that helps students book study rooms, labs, and  other resources at our college.
#Features
  For Students
 • Browse all resources (rooms, labs, equipment)
 • See details like location, capacity, etc.
 • Book resources for specific dates and times
 • Check if the resource is available before booking
 • View all your bookings
 • Cancel bookings if plans change
   For Admins
 • Add new resources to the system
 • See all bookings made by everyone
 • View statistics (how many bookings, which resources are popular)
 #Technologies Used
   • Python: The programming language
   • Tkinter: For creating the windows and buttons
   • Lists and Dictionaries: For storing data (like a digital filing cabinet)
