#BookIt – Resource Booking System (Tkinter)
 BookIt is a desktop-based resource booking system built using Python + Tkinter.
 It lets students log in, browse campus resources, make bookings, and manage them.
 Admins can add resources, view all bookings, and check system stats.
 This project simulates a mini version of a university resource management system
 
# Features
* Student
  Login with username & password
  Browse available resources
  Book resources with date & time
  Prevents overlapping/conflicting bookings
  View and cancel personal bookings
* Admin
  Add new resources
  View all bookings in the system
  View basic system statistics
  Total users
  Total resources
  Total bookings

# Preloaded Data
  Sample users (students + admin)
  Sample resources
  Pre-populated bookings
  
#UI Overview
   The app uses:
   Tkinter
